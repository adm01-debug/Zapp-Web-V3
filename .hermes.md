## Barreiras (cadeado físico)
O plugin project-guard BLOQUEIA (mensagem de erro clara):
1. write_file/patch para fora deste projeto e das raízes permitidas (TEMP, ~/auditorias, ~/backups, HERMES_HOME, worktrees).
2. Terminal: mkdir/redirecionamento de escrita para fora das raízes.
3. execute_code: escrita de arquivo para fora das raízes.
4. .hermes-chats FORA de um projeto (pasta de chat só existe dentro do projeto dono).
Se um bloqueio acontecer: use C:\zapp-web-v3\.hermes-chats\<id-da-sessao>\ para artefatos do chat, subpasta do projeto para código, ou ~/auditorias/<tipo>/ para artefatos genéricos. Desligar o cadeado (PROJECT_GUARD_OFF=1) é proibido sem ordem do Joaquim.
